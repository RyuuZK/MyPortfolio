# MyPortfolio

Meu portfólio pessoal como desenvolvedor, com projetos em Roblox/Luau,
sites e bots de Discord.

🔗 **[Ver o site ao vivo](https://ryuuzk.github.io/MyPortfolio/#home)**

---

## Sobre

Site feito para apresentar meus trabalhos e serviços como
desenvolvedor freelancer. Reúne projetos com vídeos de
demonstração e meus contatos para orçamento.

## Funcionalidades

- Seção de projetos com vídeos de demonstração
- Versão em **português e inglês**
- Layout responsivo (celular e desktop)
- Navegação por seções na mesma página
